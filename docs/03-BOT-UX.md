# UX-спецификация: диалоги и тексты бота

**Язык интерфейса:** русский. Обращение на «ты». Эмодзи — умеренно, как визуальные якоря.

---

## 1. Онбординг

**`/start` (новый пользователь, в allowlist):**

```
Привет! 👋 Я помогу быстро создавать события в календаре прямо из Telegram.

Сначала настроим две вещи: часовой пояс и календарь.

В каком ты часовом поясе?
```
Клавиатура: `Europe/Warsaw` · `Europe/Moscow` · `Europe/Kyiv` · `Asia/Tel_Aviv` · `⌨️ Ввести другой`

При «Ввести другой»:
```
Напиши таймзону в формате IANA, например: Europe/Berlin
Список: en.wikipedia.org/wiki/List_of_tz_database_time_zones
```
Невалидная → `Не узнаю такую таймзону. Пример правильной: Europe/Berlin`

**После выбора таймзоны:**
```
✅ Часовой пояс: Europe/Warsaw

Теперь подключим календарь. Можно оба — потом выберешь основной.
```
Клавиатура: `🟦 Google Calendar` · `🍎 Apple iCloud` · `Готово`

**Google:**
```
Открой ссылку и разреши доступ к календарю:
<ссылка>

Ссылка живёт 10 минут. Как разрешишь — я напишу.
```
После callback: `✅ Google Calendar подключён.`

**iCloud:**
```
🍎 Для iCloud нужен пароль приложения — обычный пароль от Apple ID не подойдёт.

1. Зайди на appleid.apple.com → «Вход и безопасность» → «Пароли приложений»
2. Создай новый пароль, назови его, например, «Telegram Bot»
3. Пришли мне одним сообщением:

твой@apple.id
xxxx-xxxx-xxxx-xxxx

Сообщение с паролем я удалю сразу после проверки.
```
После проверки: бот удаляет сообщение пользователя и пишет
```
✅ iCloud подключён. Сообщение с паролем удалено.
```
При ошибке: `❌ Не получилось войти. Проверь Apple ID и пароль приложения и пришли ещё раз.`

**Завершение:**
```
Всё готово 🎉

/new — создать событие
/events — мои события
/settings — настройки

Начнём?
```

**`/start` (не в allowlist):**
```
Привет! Пока бот работает в закрытом режиме. Если тебе нужен доступ — напиши владельцу бота.
```

## 2. Создание события — `/new`

**Шаг 1. Название**
```
📝 Название события?
```
Клавиатура: `❌ Отмена`
Пустой ввод → `Название не может быть пустым. Напиши, как назвать событие.`
Длиннее 200 символов → `Слишком длинно. Уложись в 200 символов.`

**Шаг 2. Описание**
```
Добавить описание?
```
Клавиатура: `⏭ Пропустить` · `❌ Отмена`

**Шаг 3. Дата**
```
📅 На какую дату?
```
Инлайн-календарь + кнопки `⌨️ Ввести дату` · `❌ Отмена`
Быстрые кнопки над сеткой: `Сегодня` · `Завтра`
Ручной ввод: `Напиши дату в формате дд.мм.гггг, например 14.08.2026`
Невалидная → `Не разобрал дату. Нужен формат дд.мм.гггг, например 14.08.2026`
Прошедшая дата → `⚠️ Это прошедшая дата. Всё равно создать?` → `Да` / `Выбрать другую`

**Шаг 4. Тип**
```
Событие на весь день или на конкретное время?
```
Клавиатура: `🌞 Весь день` · `🕐 Указать время` · `❌ Отмена`

**Шаг 5. Время начала** *(только при «Указать время»)*
```
🕐 Во сколько начало? Формат ЧЧ:ММ, например 15:00
```
Невалидное → `Не разобрал время. Нужен формат ЧЧ:ММ, например 09:30`

**Шаг 6. Длительность**
```
⏱ Сколько длится?
```
Клавиатура: `30 мин` · `1 час` · `1.5 часа` · `2 часа` · `⌨️ Своя` · `❌ Отмена`
При «Своя»: `Напиши длительность: 45м, 2ч, 1ч30м`
Невалидная → `Не разобрал. Примеры: 45м, 2ч, 1ч30м`
Больше 24 часов → `Максимум 24 часа. Для более долгих событий выбери «Весь день».`

**Шаг 7. Календарь по умолчанию** *(только при первом создании, если подключены оба)*
```
У тебя подключены Google и iCloud. В какой создавать события по умолчанию?
Потом можно поменять в /settings.
```
Клавиатура: `🟦 Google` · `🍎 iCloud`

**Шаг 8. Превью**
```
📋 Проверь событие

Название: Визит к врачу
Описание: Кабинет 305, взять анализы
Дата: 14.08.2026 (четверг)
Время: 15:00 – 16:00 (Europe/Warsaw)
Напоминание: за 30 минут
Календарь: Google Calendar
```
Клавиатура: `✅ Отправить` · `✏️ Изменить` · `❌ Отменить`

Строка «Описание» не выводится, если описание пропущено.
Для all-day строка времени: `Время: весь день`

**«✏️ Изменить»:**
```
Что поменять?
```
Клавиатура: `Название` · `Описание` · `Дата` · `Время` · `Длительность` · `Календарь` · `⬅️ Назад к превью`
После изменения одного поля — сразу обратно к превью.

**«✅ Отправить»:**
Кнопки немедленно гаснут, сообщение редактируется в `⏳ Создаю событие…`, затем:
```
✅ Событие создано

Визит к врачу
14.08.2026, 15:00 – 16:00
Google Calendar
```
Клавиатура: `🗑 Удалить` · `➕ Ещё одно`

**«❌ Отменить»:** `Отменил. Ничего не создано.`

**Ошибка при создании:**
```
❌ Не получилось создать событие: календарь не отвечает.
Черновик сохранён — можно попробовать ещё раз.
```
Клавиатура: `🔄 Повторить` · `❌ Отменить`

## 3. Список событий — `/events`

```
📆 Ближайшие события (1–5 из 8)

1. Визит к врачу
   14.08, 15:00 – 16:00 · Google

2. Родительское собрание
   16.08, весь день · iCloud

3. Созвон с командой
   17.08, 11:00 – 11:30 · Google
```
Клавиатура: строка кнопок `🗑 1` `🗑 2` `🗑 3` `🗑 4` `🗑 5`, ниже `◀️` `▶️`

Пусто:
```
Пока нет предстоящих событий, созданных через бота.
/new — создать первое
```

**Удаление:**
```
Удалить событие?

Визит к врачу
14.08.2026, 15:00 – 16:00
```
Клавиатура: `🗑 Да, удалить` · `⬅️ Отмена`

После: `✅ Событие удалено` и обновление списка.
Если уже удалено вручную: `Это событие уже удалено из календаря. Убрал из списка.`

## 4. Настройки — `/settings`

```
⚙️ Настройки

Часовой пояс: Europe/Warsaw
Календарь по умолчанию: Google Calendar
Подключено: Google ✅, iCloud ✅
Напоминание: за 30 минут
```
Клавиатура:
`🌍 Часовой пояс`
`📅 Календарь по умолчанию`
`🔗 Подключить / отключить календарь`
`🗑 Удалить все мои данные`

**Удаление данных:**
```
⚠️ Это удалит твой профиль, подключённые календари и историю событий из бота.
Сами события в календаре останутся.

Точно удалить?
```
Клавиатура: `Да, удалить всё` · `Отмена`

*Пункт «Напоминание» в итерации 1 только отображается. Редактирование — итерация 3.*

## 5. Прочее

**`/cancel`:** `Отменил текущее действие.` (или `Сейчас нечего отменять.`)

**`/help`:**
```
Что я умею:

/new — создать событие пошагово
/events — посмотреть и удалить события
/settings — часовой пояс, календари
/cancel — прервать текущий диалог

Скоро: голосовые сообщения и создание события одной фразой.
```

**Незавершённый визард при `/new`:**
```
У тебя есть незаконченное событие «Визит к врачу». Продолжить или начать заново?
```
Клавиатура: `▶️ Продолжить` · `🔄 Начать заново`

**Таймаут:**
```
⌛️ Прошёл час — отменил незаконченное событие. /new чтобы начать заново.
```

**Нет подключённых календарей при `/new`:**
```
Сначала подключи календарь: /settings
```

**Непонятное сообщение вне диалога:**
```
Я пока понимаю только команды. /new — создать событие.
(Свободный текст и голосовые будут в следующей версии.)
```
