# UX-специфікація: діалоги та тексти бота

**Мова інтерфейсу:** українська. Звертання на «ти». Емодзі — помірно, як візуальні якорі.

---

## 1. Онбординг

**`/start` (новий користувач, в allowlist):**

```
Привіт! 👋 Я допоможу швидко створювати події в календарі прямо з Telegram.

Спочатку налаштуємо дві речі: часовий пояс і календар.

У якому ти часовому поясі?
```
Клавіатура: `Europe/Warsaw` · `Europe/Moscow` · `Europe/Kyiv` · `Asia/Tel_Aviv` · `⌨️ Ввести інший`

При «Ввести інший»:
```
Напиши таймзону у форматі IANA, наприклад: Europe/Berlin
Список: en.wikipedia.org/wiki/List_of_tz_database_time_zones
```
Невалідна → `Не впізнаю таку таймзону. Приклад правильної: Europe/Berlin`

**Після вибору таймзони:**
```
✅ Часовий пояс: Europe/Warsaw

Тепер підключимо календар. Можна обидва — потім виберешь основний.
```
Клавіатура: `Google Calendar` · `Apple iCloud` · `Готово`

При «Готово» без жодного підключеного календаря:
```
Спочатку підключи хоча б один календар — Google або iCloud.
```
Клавіатура: та сама (`Google Calendar` · `Apple iCloud` · `Готово`), онбординг не рухається далі.

**Google:**
```
Натисни кнопку нижче і дозволь доступ до календаря.

Посилання живе 10 хвилин. Як дозволиш — я напишу.
```
Клавіатура: `Підключити Google Calendar` (inline-кнопка з посиланням, відкриває Google напряму)

Після callback: `✅ Google Calendar підключено.`

**iCloud:**
```
🍎 Для iCloud потрібен пароль застосунку — звичайний пароль від Apple ID не підійде.

1. Зайди на appleid.apple.com → «Вхід і безпека» → «Паролі застосунків»
2. Створи новий пароль, назви його, наприклад, «Telegram Bot»
3. Надішли мені одним повідомленням:

твій@apple.id
xxxx-xxxx-xxxx-xxxx

Повідомлення з паролем я видалю одразу після перевірки.
```
Після перевірки: бот видаляє повідомлення користувача і пише
```
✅ iCloud підключено. Повідомлення з паролем видалено.
```
При помилці: `❌ Не вдалося увійти. Перевір Apple ID і пароль застосунку та надішли ще раз.`

**Завершення:**
```
Все готово 🎉

Що зробити?
```
Клавіатура: `Створити подію` · `Мої події` · `Налаштування` (inline-кнопки, не текстові команди)

Той самий екран (текст + клавіатура) показує і повторний `/start`, коли часовий пояс уже налаштований.

**`/start` (не в allowlist):**
```
Привіт! Поки що бот працює в закритому режимі. Якщо тобі потрібен доступ — напиши власнику бота.
```

## 2. Створення події — `/new`

**Крок 1. Назва**
```
📝 Назва події?
```
Клавіатура: `❌ Скасувати`
Порожній ввід → `Назва не може бути порожньою. Напиши, як назвати подію.`
Довше 200 символів → `Занадто довго. Вкладися у 200 символів.`

**Крок 2. Опис**
```
Додати опис?
```
Клавіатура: `⏭ Пропустити` · `❌ Скасувати`

**Крок 3. Дата**
```
📅 На яку дату?
```
Інлайн-календар + кнопки `⌨️ Ввести дату` · `❌ Скасувати`
Швидкі кнопки над сіткою: `Сьогодні` · `Завтра`
Ручний ввід: `Напиши дату у форматі дд.мм.рррр, наприклад 14.08.2026`
Невалідна → `Не розібрав дату. Потрібен формат дд.мм.рррр, наприклад 14.08.2026`
Минула дата → `⚠️ Це минула дата. Все одно створити?` → `Так` / `Вибрати іншу`

**Крок 4. Тип**
```
Подія на весь день чи на конкретний час?
```
Клавіатура: `🌞 Весь день` · `🕐 Вказати час` · `❌ Скасувати`

**Крок 5. Час початку** *(лише при «Вказати час»)*
```
🕐 О котрій початок? Формат ГГ:ХВ, наприклад 15:00
```
Невалідний → `Не розібрав час. Потрібен формат ГГ:ХВ, наприклад 09:30`

**Крок 6. Тривалість**
```
⏱ Скільки триває?
```
Клавіатура: `30 хв` · `1 год` · `1.5 год` · `2 год` · `⌨️ Своя` · `❌ Скасувати`
При «Своя»: `Напиши тривалість: 45хв, 2год, 1год30хв`
Невалідна → `Не розібрав. Приклади: 45хв, 2год, 1год30хв`
Більше 24 годин → `Максимум 24 години. Для довших подій вибери «Весь день».`

**Крок 7. Календар за замовчуванням** *(лише при першому створенні, якщо підключені обидва)*
```
У тебе підключені Google та iCloud. У якому створювати події за замовчуванням?
Потім можна змінити в /settings.
```
Клавіатура: `Google` · `iCloud`

**Крок 8. Перегляд**
```
📋 Перевір подію

Назва: Візит до лікаря
Опис: Кабінет 305, здати аналізи
Дата: 14.08.2026 (четвер)
Час: 15:00 – 16:00 (Europe/Warsaw)
Нагадування: за 30 хвилин
Календар: Google Calendar
```
Клавіатура: `✅ Надіслати` · `✏️ Змінити` · `❌ Скасувати`

Рядок «Опис» не виводиться, якщо опис пропущено.
Для all-day рядок часу: `Час: весь день`

**«✏️ Змінити»:**
```
Що поміняти?
```
Клавіатура: `Назва` · `Опис` · `Дата` · `Час` · `Тривалість` · `Календар` · `⬅️ Назад до перегляду`
Після зміни одного поля — одразу назад до перегляду.

**«✅ Надіслати»:**
Кнопки одразу гаснуть, повідомлення редагується на `⏳ Створюю подію…`, потім:
```
✅ Подію створено

Візит до лікаря
14.08.2026, 15:00 – 16:00
Google Calendar
```
Клавіатура: `🗑 Видалити` · `➕ Ще одна`

**«❌ Скасувати»:** `Скасував. Нічого не створено.`

**Помилка при створенні:**
```
❌ Не вдалося створити подію: календар не відповідає.
Чернетку збережено — можна спробувати ще раз.
```
Клавіатура: `🔄 Повторити` · `❌ Скасувати`

## 3. Список подій — `/events`

```
📆 Найближчі події (1–5 з 8)

1. Візит до лікаря
   14.08, 15:00 – 16:00 · Google

2. Батьківські збори
   16.08, весь день · iCloud

3. Дзвінок з командою
   17.08, 11:00 – 11:30 · Google
```
Клавіатура: рядок кнопок `🗑 1` `🗑 2` `🗑 3` `🗑 4` `🗑 5`, нижче `◀️` `▶️`

Порожньо:
```
Поки немає майбутніх подій, створених через бота.
/new — створити першу
```

**Видалення:**
```
Видалити подію?

Візит до лікаря
14.08.2026, 15:00 – 16:00
```
Клавіатура: `🗑 Так, видалити` · `⬅️ Скасувати`

Після: `✅ Подію видалено` та оновлення списку.
Якщо вже видалено вручну: `Цю подію вже видалено з календаря. Прибрав зі списку.`

## 4. Налаштування — `/settings`

```
⚙️ Налаштування

Часовий пояс: Europe/Warsaw
Календар за замовчуванням: Google Calendar
Підключено: Google ✅, iCloud ✅
Нагадування: за 30 хвилин
```
Клавіатура:
`🌍 Часовий пояс`
`📅 Календар за замовчуванням`
`🔗 Підключити / відключити календар`
`🗑 Видалити всі мої дані`

**Видалення даних:**
```
⚠️ Це видалить твій профіль, підключені календарі та історію подій з бота.
Самі події в календарі залишаться.

Точно видалити?
```
Клавіатура: `Так, видалити все` · `Скасувати`

*Пункт «Нагадування» в ітерації 1 лише відображається. Редагування — ітерація 3.*

## 5. Інше

**`/cancel`:** `Скасував поточну дію.` (або `Зараз нема чого скасовувати.`)

**`/help`:**
```
Що я вмію:

/new — створити подію покроково
/events — переглянути та видалити події
/settings — часовий пояс, календарі
/cancel — перервати поточний діалог

Скоро: голосові повідомлення та створення події однією фразою.
```

**Незавершений візард при `/new`:**
```
У тебе є незакінчена подія «Візит до лікаря». Продовжити чи почати заново?
```
Клавіатура: `▶️ Продовжити` · `🔄 Почати заново`

**Таймаут:**
```
⌛️ Минула година — скасував незакінчену подію. /new щоб почати заново.
```

**Немає підключених календарів при `/new`:**
```
Спочатку підключи календар:
```
Клавіатура: `Налаштування` (inline-кнопка, відкриває `/settings`)

**Часовий пояс ще не налаштований при `/new`** *(захисний краєвий випадок — при штатному онбордингу недосяжний)*:
```
Спочатку заверши налаштування часового поясу:
```
Клавіатура: `Почати` (inline-кнопка, відкриває `/start`)

**Занадто багато дій підряд (rate limit):**
```
Забагато дій підряд. Зачекай трохи і спробуй знову.
```

**Незрозуміле повідомлення поза діалогом:**
```
Я поки розумію лише команди. /new — створити подію.
(Вільний текст і голосові будуть у наступній версії.)
```

## 6. Меню команд (кнопка ☰ біля поля вводу)

Встановлюється через `setMyCommands` при старті бота (`registerBotCommands` у `src/bot/bot.ts`), не в діалозі — але текст описів так само видно користувачу, тому фіксуємо тут.

| Команда | Опис у меню |
|---|---|
| `/start` | Почати / перезапустити бота |
| `/new` | Створити подію |
| `/events` | Мої події |
| `/settings` | Часовий пояс, календарі |
| `/cancel` | Перервати поточний діалог |
| `/help` | Що вміє бот |

## 7. Сторінки Google OAuth (браузер)

Ці тексти показуються не в Telegram, а на проміжній HTML-сторінці браузера під час підключення Google Calendar (`src/routes/oauthGoogle.ts`).

**Посилання недійсне або протермінувалося:**
```
Посилання недійсне або протермінувалося. Повернись у Telegram і спробуй знову.
```

**Успіх:**
```
Можна повернутися в Telegram.
```

**Загальна помилка:**
```
Не вдалося підключити Google Calendar. Повернись у Telegram і спробуй знову.
```
