# UX-специфікація: діалоги та тексти бота

**Мова інтерфейсу:** українська. Звертання на «ти». Без емодзі — простий текст.

---

## 1. Онбординг

**`/start` (новий користувач, в allowlist):**

```
Привіт! Я допоможу швидко створювати події в календарі прямо з Telegram.

Спочатку налаштуємо дві речі: часовий пояс і календар.

У якому ти часовому поясі?
```
Клавіатура (по дві в ряд): `Europe/London` `Europe/Warsaw` · `Europe/Kyiv` · `Ввести інший`

При «Ввести інший»:
```
Напиши таймзону у форматі IANA, наприклад: Europe/Berlin
Список: en.wikipedia.org/wiki/List_of_tz_database_time_zones
```
Невалідна → `Не впізнаю таку таймзону. Приклад правильної: Europe/Berlin`

**Після вибору таймзони:**
```
Часовий пояс: Europe/Warsaw

Тепер підключимо Google Calendar.
```

**Google:**
```
Натисни кнопку нижче і дозволь доступ до календаря.

Посилання живе 10 хвилин. Як дозволиш — я напишу.
```
Клавіатура: `Підключити Google Calendar` (inline-кнопка з посиланням, відкриває Google напряму)

Якщо Telegram відхиляє URL кнопки (наприклад, `BASE_URL` вказує на `localhost` — типово для локальної розробки без тунелю):
```
Скопіюй посилання і відкрий у браузері на цьому ж комп'ютері (Telegram не дозволяє кнопку для localhost):
<посилання>

Посилання живе 10 хвилин. Як дозволиш — я напишу.
```

Одразу після цього:
```
Як підключиш — натисни «Готово».
```
Клавіатура: `Готово`

Після callback від Google (асинхронно, поки користувач у браузері): `Google Calendar підключено.` — окреме повідомлення, не заміна екрана вище.

При натисканні «Готово» без завершеного підключення:
```
Спочатку підключи Google Calendar.
```
Клавіатура: `Готово`, онбординг не рухається далі.

**Завершення:**
```
Все готово!

Що зробити?
```
Клавіатура: `Створити подію` · `Мої події` · `Налаштування` (inline-кнопки, не текстові команди)

Той самий екран (текст + клавіатура) показує і повторний `/start`, коли часовий пояс уже налаштований.

**`/start` (не в allowlist):**
```
Привіт! Поки що бот працює в закритому режимі. Якщо тобі потрібен доступ — напиши власнику бота.
```

## 2. Створення події — `/new`

**Крок 1. Назва**
```
Назва події?
```
Клавіатура: `Скасувати`
Порожній ввід → `Назва не може бути порожньою. Напиши, як назвати подію.`
Довше 200 символів → `Занадто довго. Вкладися у 200 символів.`

**Крок 2. Опис**
```
Додати опис?
```
Клавіатура: `Пропустити` · `Скасувати`

**Крок 3. Дата**
```
На яку дату?
```
Клавіатура: `Сьогодні` · `Завтра` · `Своя дата` · `Календар` · `Скасувати`

«Своя дата» → `Напиши дату у форматі ДД/ММ/РРРР, наприклад 14/08/2026`
«Календар» → інлайн-календар (сітка з навігацією по місяцях, кнопка `Ввести дату` внизу — той самий ручний ввід)
Невалідна → `Не розібрав дату. Потрібен формат ДД/ММ/РРРР, наприклад 14/08/2026`
Минула дата → `Це минула дата. Все одно створити?` → `Так` / `Вибрати іншу`

**Крок 4. Тип**
```
Подія на весь день чи на конкретний час?
```
Клавіатура: `Весь день` · `Вказати час` · `Скасувати`

**Крок 5. Час початку** *(лише при «Вказати час»)*
```
О котрій початок? Формат ГГ:ХВ, наприклад 15:00
```
Невалідний → `Не розібрав час. Потрібен формат ГГ:ХВ, наприклад 09:30`

**Крок 6. Тривалість**
```
Скільки триває?
```
Клавіатура: `30 хв` · `1 год` · `1.5 год` · `2 год` · `Своя` · `Скасувати`
При «Своя»: `Напиши тривалість: 45хв, 2год, 1год30хв`
Невалідна → `Не розібрав. Приклади: 45хв, 2год, 1год30хв`
Більше 24 годин → `Максимум 24 години. Для довших подій вибери «Весь день».`

**Крок 7. Колір** *(запитується завжди — і для all-day, і для подій з часом)*
```
Замінити колір події?
```
Клавіатура (по дві кнопки в рядку): `Червоний` `Жовтий` · `Зелений` `Синій` · `Ні` · `Скасувати`

Список — 4 найбільш впізнавані та відмінні один від одного кольори з фіксованої палітри Google Calendar (довільний hex недоступний через API). «Ні» — колір не встановлюється (як і раніше, значення за замовчуванням).

**Крок 8. Перегляд**
```
Перевір подію

Назва: Візит до лікаря
Опис: Кабінет 305, здати аналізи
Дата: 14.08.2026 (четвер)
Час: 15:00 – 16:00 (Europe/Warsaw)
Колір: Синій
Нагадування: за 30 хвилин
Календар: romawcka@gmail.com
```
Клавіатура: `Надіслати` · `Змінити` · `Скасувати`

Рядок «Опис» не виводиться, якщо опис пропущено. Рядок «Колір» не виводиться, якщо колір пропущено.
Для all-day рядок часу: `Час: весь день`
Рядок «Календар» показує email основного акаунта (або того, що обрано через «Календар» в «Змінити» — див. §4). Якщо календар ще не підключено на момент перегляду: `Календар: не підключено` (див. «Немає підключеного календаря на етапі надсилання» нижче — блокує лише сам `Надіслати`, не показ прев'ю).

**«Змінити»:**
```
Що поміняти?
```
Клавіатура: `Назва` · `Опис` · `Дата` · `Час` · `Тривалість` · `Колір` · `Назад до перегляду`, і додатково `Календар` — лише коли активних Google-акаунтів два і більше (див. §4).
Після зміни одного поля — одразу назад до перегляду. «Календар» відкриває список активних акаунтів; вибір діє лише для цієї події, основний акаунт не змінюється. «Колір» показує ті самі 4 кнопки кроку 7; вибір «Ні» знову прибирає колір.

**«Надіслати»:**
Кнопки одразу гаснуть, повідомлення редагується на `Створюю подію…`, потім:
```
Подію створено

Візит до лікаря
14.08.2026, 15:00 – 16:00
romawcka@gmail.com
```
Клавіатура: `Видалити` · `Ще одна`

**«Скасувати»:** `Скасував. Нічого не створено.`

**Помилка при створенні:**
```
Не вдалося створити подію: календар не відповідає.
Чернетку збережено — можна спробувати ще раз.
```
Клавіатура: `Повторити` · `Скасувати`

## 3. Список подій — `/events`

```
Найближчі події (1–5 з 8)

1. Візит до лікаря
   14.08, 15:00 – 16:00 · Google

2. Батьківські збори
   16.08, весь день · Google

3. Дзвінок з командою
   17.08, 11:00 – 11:30 · Google
```
Клавіатура: рядок кнопок `Видалити 1` `Видалити 2` `Видалити 3` `Видалити 4` `Видалити 5`, нижче `Назад` `Вперед`, і ще нижче — `Видалити всі` (тільки якщо подій у всьому списку більше однієї, не лише на поточній сторінці).

Список звіряється з Google Calendar (щоб побачити події, видалені вручну прямо в календарі) не частіше ніж раз на хвилину, і тільки при відкритті `/events` — перегортання сторінок і видалення саме по собі календар не смикають.

Порожньо:
```
Поки немає майбутніх подій, створених через бота.
/new — створити першу
```

**Видалення одного:**
```
Видалити подію?

Візит до лікаря
14.08.2026, 15:00 – 16:00
```
Клавіатура: `Так, видалити` · `Скасувати`

Після: `Подію видалено` та оновлення списку.
Якщо вже видалено вручну: `Цю подію вже видалено з календаря. Прибрав зі списку.`

**Видалення всіх:**
```
Видалити всі 8 подій із календаря?

Цю дію не можна скасувати.
```
Клавіатура: `Так, видалити всі` · `Скасувати`

Під час видалення: `Видаляю події…`

Після — при повному успіху: `Видалено 8 подій`
При частковому (частину не вдалося видалити через збій календаря): `Видалено 6 з 8. 2 не вдалося видалити — спробуй ще раз пізніше.`

## 4. Налаштування — `/settings`

```
Налаштування

Часовий пояс: Europe/Warsaw
Google-акаунти: 2 підключено, основний romawcka@gmail.com
Нагадування: за 30 хвилин
```
Якщо жодного акаунта не підключено: рядок `Google-акаунти: не підключено`.

Клавіатура:
`Часовий пояс`
`Google-акаунти`
`Видалити всі мої дані`

**«Google-акаунти»** — список підключених акаунтів (можна підключити більше одного, різні логіни Google — не кілька календарів усередині одного акаунта, див. `docs/features/04-multiple-google-accounts.md`):
```
Google-акаунти
```
Клавіатура: по одній кнопці на акаунт (позначка «(основний)» після email — позначка основного), потім `Підключити ще один акаунт` (або `Підключити акаунт`, якщо підключених ще немає), потім `Назад`.

Тап по акаунту зі списку — його власні дії:
```
work@company.com
```
Клавіатура: `Зробити основним` (не показується, якщо він уже основний) · `Відключити` · `Назад`

Підключення ще одного акаунта — та сама кнопка з посиланням, що й раніше; вибір саме іншого логіна робить сам Google на екрані згоди. Повторне підключення того самого логіна лише оновлює токени на тому ж акаунті, дублікат не створюється.

В прев'ю події (крок 8 вище) рядок «Календар» показує email акаунта, у який піде подія (основний, якщо не перевизначено через «Змінити» → «Календар» — цей пункт з'являється лише коли активних акаунтів два і більше).

**Видалення даних:**
```
Це видалить твій профіль, підключені календарі та історію подій з бота.
Самі події в календарі залишаться.

Точно видалити?
```
Клавіатура: `Так, видалити все` · `Скасувати`

*Пункт «Нагадування» в ітерації 1 лише відображається. Редагування — ітерація 3.*

## 5. Інше

**`/cancel`:** `Скасував поточну дію.` (або `Зараз нема чого скасовувати.`)

**`/new` під час `/settings`:** налаштування не мають чернетки, яку шкода втратити (на відміну від `/new` під час `/new`, де питаємо «Продовжити чи почати заново?») — просто виходимо з налаштувань:
```
Вийшов із налаштувань.
```
Клавіатура: `Створити подію` (inline-кнопка, одразу стартує візард)

**`/help`:**
```
Що я вмію:

/new — створити подію покроково
/events — переглянути та видалити події
/settings — часовий пояс, календарі
/cancel — перервати поточний діалог

Скоро: голосові повідомлення та створення події однією фразою.
```

**Незавершений візард при `/new`:**
```
У тебе є незакінчена подія «Візит до лікаря». Продовжити чи почати заново?
```
Клавіатура: `Продовжити` · `Почати заново`

**Таймаут:**
```
Минула година — скасував незакінчену подію. /new щоб почати заново.
```

**Будь-яка інша команда (`/events`, `/settings` тощо) під час активного кроку візарда** (окрім `/cancel` і `/new`, які оброблені окремо вище) — команда не приймається як значення поточного поля, крок лишається незавершеним:
```
Спочатку заверши створення події або натисни «Скасувати».
```

**Немає підключеного календаря на етапі надсилання:** `/new` більше не блокується на старті — відсутність календаря перевіряється лише в момент `Надіслати` (усі поля вже зібрані й нікуди не діваються):
```
Щоб надіслати подію, спочатку підключи Google Calendar:
```
Клавіатура: та сама кнопка підключення, що й у `/settings` (inline-кнопка з посиланням).

Довільний текст, поки бот чекає на підключення:
```
Спочатку підключи календар, натиснувши кнопку вище, або натисни «Скасувати».
```

Після успішного підключення саме з цього кроку (не з `/settings`):
```
Google Calendar підключено. Можеш продовжити створення події.
```
Клавіатура: `Продовжити` — повертає до екрана перегляду з усіма вже введеними полями, нічого не питається заново.

Якщо натиснути «Продовжити» вже після таймауту незакінченого візарда (60 хв):
```
Ця подія вже неактуальна. Почни заново: /new
```

**Часовий пояс ще не налаштований при `/new`** *(захисний краєвий випадок — при штатному онбордингу недосяжний)*:
```
Спочатку заверши налаштування часового поясу:
```
Клавіатура: `Почати` (inline-кнопка, відкриває `/start`)

**Занадто багато дій підряд (rate limit):**
```
Забагато дій підряд. Зачекай трохи і спробуй знову.
```

**Незрозуміле повідомлення поза діалогом:**
```
Я поки розумію лише команди. /new — створити подію.
(Вільний текст і голосові будуть у наступній версії.)
```

## 6. Меню команд (кнопка списку команд біля поля вводу)

Встановлюється через `setMyCommands` при старті бота (`registerBotCommands` у `src/bot/bot.ts`), не в діалозі — але текст описів так само видно користувачу, тому фіксуємо тут.

| Команда | Опис у меню |
|---|---|
| `/start` | Почати / перезапустити бота |
| `/new` | Створити подію |
| `/events` | Мої події |
| `/settings` | Часовий пояс, календарі |
| `/cancel` | Перервати поточний діалог |
| `/help` | Що вміє бот |

## 7. Сторінки Google OAuth (браузер)

Ці тексти показуються не в Telegram, а на проміжній HTML-сторінці браузера під час підключення Google Calendar (`src/routes/oauthGoogle.ts`).

**Посилання недійсне або протермінувалося:**
```
Посилання недійсне або протермінувалося. Повернись у Telegram і спробуй знову.
```

**Успіх:**
```
Можна повернутися в Telegram.
```

**Загальна помилка:**
```
Не вдалося підключити Google Calendar. Повернись у Telegram і спробуй знову.
```
